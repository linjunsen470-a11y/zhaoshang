# 广州锦奕咨询服务有限公司静态官网

`website/` 是不依赖构建工具的静态网站：直接打开 `index.html` 可本地预览。包含首页、业务、企业信息和联系方式四页。

页面仅介绍企业信息、咨询业务和联系方式，不含表单或第三方资源。`Dockerfile` 和 `server.mjs` 保留为轻量静态文件服务，不包含后端或数据库。

样式源文件为 `css/style.css`；为避免浏览器缓存或独立样式请求失败导致页面失去样式，四个 HTML 页面内联同一份 CSS。修改样式后在仓库根目录运行 `node scripts/sync-website-inline-css.mjs`；可用 `node scripts/sync-website-inline-css.mjs --check` 检查四个页面是否同步。

## 仓库边界

当前继续保留在本仓库的 `website/` 目录，独立部署。官网与小程序属于同一业务，现有测试会核对企业和联系方式的一致性；拆仓库会增加重复维护和跨仓库校验，目前收益有限。GitHub CI 仅手动运行代码检查，不自动构建或部署。以后出现独立维护团队、访问权限或产品发布边界时，再考虑拆仓库。

## 备案与发布

- 企业名称、登记地址和统一社会信用代码来自营业执照；联系电话由用户提供。
- 目前没有已核发的网站备案号，页脚不展示占位号或已通过备案的声明。取得网站服务备案号后，填写 `js/main.js` 中的 `SITE_ICP_NUMBER`，重新部署后页脚自动显示并链接至工信部网站。小程序备案号应单独填写到 `mp/config/index.js`。
- 中国大陆接入需要联系实际的大陆接入服务商办理备案，不应以境外部署代替备案接入信息。
- 腾讯云要求首次备案或新增未备案网站在备案成功前不可公开访问；如适用，需由域名管理人暂停当前指向 Railway 的解析，并核对其他公网入口。页面内容和备案申请应与实际业务一致，具体以腾讯云和备案订单要求为准。
- 官网与后端是不同的部署：本目录不含客户资料、数据库、Payload 管理后台或小程序 API。不要把整个仓库、营业执照照片或 `.env` 打包进静态站点。
- 域名、生产环境、微信合法域名和上线前验收步骤见 [企业备案与小程序上线准备](../docs/企业备案与小程序上线准备.md)。具体审核要求以实际接入商和广东管局为准。
