# 小程序咨询表单说明

首次提交只收集联系用户和识别基本需求所需的信息。补充说明和其他选填内容直接显示；隐私确认和提交按钮固定在底部。

| 入口 | 必填 | 选填 | 自动带入 |
| --- | --- | --- | --- |
| 咨询具体房源 | 手机号 | 说明、称呼 | 房源、来源、咨询类型和房源场景 |
| 帮我找铺 | 手机号 | 区域或学校、说明、称呼 | 来源、咨询类型；明确场景入口带入场景 |
| 店铺转让 | 手机号、所在城市或区域 | 说明、称呼、图片 | 来源、转让类型 |
| 设备供需 | 手机号、设备名称和供需类型 | 说明、称呼、图片 | 来源；明确类型的入口带入类型 |
| 装修咨询 | 手机号 | 区域或学校、说明、称呼 | 来源、装修咨询类型 |

手机号可手动填写或通过微信授权获取，详见 [联系方式与微信授权](wechat-contact-authorization.md)。店铺位置不要求具体门牌；设备图片不是提交条件，设备资料仍须审核后才可公开。

经营品类、投资预算、校园经营经验、转让费、合同期、设备规格和装修细节由顾问后续了解或在后台补充。后台将未填写的称呼显示为未填写，未询问的校园经营经验和设备包含情况不应当作用户明确回答。

后端继续校验手机号、转让区域、设备名称、房源可咨询状态与附件归属；编辑只更新用户提交的字段并保留后台补充资料，首次咨询快照保持不变。称呼字段可为空，数据库需按照 [结构维护说明](schema-setup.md) 显式更新。
