# 小程序界面升级与验收记录

日期：2026-10-15。范围：微信小程序 12 个页面及其客户端测试、设计预览工具。官网与管理后台未纳入本轮。

## 已实施

- 白底、深绿、浅灰绿分区；统一字体层级、32rpx 页面边距、16rpx 卡片与图片圆角、12rpx 输入圆角。
- 首页突出搜索与场景，四个服务入口保持顺序；推荐上图下文，首屏呈现推荐内容。
- 首页最新房源与找铺列表共享 WXML 模板和样式，费用标签沿用展示层语义，年费不会被标为月租。
- 找铺使用场景、内容切换与四个主要筛选入口；更多筛选先暂存，确认才请求，关闭不应用；已选条件可移除，非校园场景清理校园细类。
- 详情按费用与面积、空间信息、经营条件、介绍、所属铺位、合作与看铺组织；保留分享、电话、收藏和咨询。
- 四类表单保留字段旁报错与首错定位；上传／提交／加载异常时阻止提交。当前精简字段以 [咨询表单说明](小程序咨询表单精简方案.md) 为准。
- 我的、咨询记录、设备、成功、隐私页面统一层级；记录编辑降为次级操作，删除保留确认；增加设备与咨询记录错误重试及图片失败占位。
- 新增四类场景摄影示意图，仅本地演示使用并明确标识；正式房源缺图显示中性占位。
- 保留 API 参数、表单字段、商业字典生成来源、路由和现有自动化事件钩子。

## 验证与证据

| 项目 | 结果 |
| --- | --- |
| 客户端单元测试 | 23 项通过；包括新增筛选暂存／取消／确认、校园条件清理、表单首错定位、清空确认等 |
| 微信 WXML 编译 | 全部页面和共享模板通过开发者工具自带的 wcc |

| 浏览器布局检查 | 320／375／430px，12 个正常页面及 11 个状态，共 69 个组合均可渲染；未发现非横滑区域溢出或图片加载失败 |

实施前源码快照和历史测试产物已于 2026-10-31 按要求清理。浏览器布局预览使用当前 WXML、WXSS 和隔离的演示数据，原生控件、键盘、滚动与业务操作仍需在微信环境验收。

## 复现

```powershell
# 客户端规则与交互逻辑
node --test --test-isolation=none tests/unit/*.test.mjs

# 原生模板与样式编译；安装目录不同时设置 MP_COMPILER_DIR
node scripts/mp-check-templates.mjs

# 基于实际源文件的布局预览，访问 http://127.0.0.1:5174
node scripts/mp-design-preview.mjs --serve

# 开发者工具开启 auto 端口后，运行不依赖后端的单连接回归
node --test --test-force-exit --test-isolation=none tests/mp-interface.test.mjs

# 尝试采集原生页面截图；失败时保留源码与错误诊断
node scripts/mp-visual-review.mjs
```

`mp-design-preview` 的 HTTP 接口仅提供只读的公开演示房源，不能替代 API 集成测试后端。所有预览数据在 Node VM 的独立存储中生成。原生单连接回归在修改 local mock 前备份，并在结束时恢复。
