# 商业项目与铺位：运营录入说明

适用范围：广州校园商铺、社区商业、文旅街区、购物中心。由团队统一录入和跟进，前台不使用“低端”标签。本轮没有商户台账、短信发送、外部物业账号或在线交易。

## 1. 先选发布内容，再选场景

进入后台「项目与铺位」→「新建房源」。

| 发布内容 | 使用情况 | 注意事项 |
| --- | --- | --- |
| 项目招商 | 对一个商业项目整体介绍招商条件 | 只能招商；没有明确铺位也可以发布，不填写虚构空铺数量 |
| 具体铺位 | 有明确位置的单个铺位，或转让商铺 | 可关联整项目，也可作为独立街铺 |

四类场景和发布内容是两个独立维度。校园记录保留学校名称、简称及校园细类；社区、文旅和购物中心使用「商业项目/位置名称」。

## 2. 项目和铺位关联

在已保存的整项目详情或列表点击「新增所属铺位」，系统预填所属项目、场景、城市和地区。填写楼层/铺位位置后保存。

- 一个铺位最多关联一个整项目。整项目不能关联父项目，铺位不能作为父项目。
- 双方场景、城市和地区必须一致。有子铺位的项目不能直接更改这些信息或改成铺位；先处理关联。
- 父项目为草稿或下架时，子铺位暂停公开，各自状态仍保留；父项目恢复后按子铺位自身状态恢复展示。
- 父项目「已满」不代表所有子铺位都已满，须人工检查各自状态。
- 删除有子铺位的父项目会被阻止。先解除关联或处理子记录。

## 3. 面积和月租填写规则

| 内容 | 示例 | 填写方式 |
| --- | --- | --- |
| 固定面积 | 80㎡ | 下限 80，上限 80 |
| 项目可招商单元范围 | 30—200㎡ | 下限 30，上限 200；不是整个商业体建筑面积 |
| 固定基础月租 | 8000元/月 | 下限 8000，上限 8000 |
| 基础月租范围 | 5000—15000元/月 | 下限 5000，上限 15000 |
| 尚未核实/月租面议 | 未知 | 两端同时留空，不填 0；在费用说明中解释 |

面积必须大于 0；月租可为 0（仅限真实确认的免基础租金情形）。上下限需同时填写或同时留空，上限不得小于下限。月租不自动包含物业费、推广费、扣点、转让费或押金。

「面积」「费用说明」继续用于展示详细条款；数值范围用于筛选，两者需同步核对。快速修改支持同时维护范围、展示说明、状态和排序。总投资预算属于商户咨询需求，不用于房源租金筛选。

筛选区间下限包含、上限不包含。例如 50㎡不属于“50㎡以下”，属于“50—100㎡”；项目范围 30—100㎡与“100—200㎡”存在 100㎡交集，因此可以匹配。缺失数值的记录只在未设置相应筛选时展示。

## 4. 各场景重点补充

| 场景 | 必须向项目方核实的内容 |
| --- | --- |
| 校园商铺 | 学校、校园细类、校内外位置、经营和进校要求 |
| 社区商业 | 周边居民/办公客群、主要营业时段、适合品类 |
| 文旅街区 | 旺淡季、建议经营时段、常驻经营要求；本轮不承接临时摊位系统 |
| 购物中心 | 是否接纳个体和非连锁品牌、品牌/证照准入、营业时长要求 |
| 通用 | 排烟、燃气、上下水、电力、费用、看铺安排；未知条件明确写“待核实” |

上架检查要求标题、封面、地区、费用说明、客群说明和详情图片；新记录必须选择场景。完整录入还应包含介绍、地址、经营要求、适合品类和看铺安排。运营应确认图片授权、真实性与有效期后再上架。

## 5. 咨询承接

详情页咨询自动关联当前项目或铺位，用户可看到咨询对象。通用咨询允许意向场景「不限」。姓名、电话之外继续以原有表单收集经营品类、总投资预算、区域、备注和附件；面积、租金承受能力先写在备注中。

「校园经营经验」仅校园场景展示。后台咨询收件箱显示关联对象和场景，按「待联系→已联系→已结束」人工跟进。用户编辑咨询不能更换原关联对象；首次原文快照不会被后续编辑覆盖。

## 6. 上线前内容验收

测试样例和带「演示」的内容仅用于测试，不应导入正式库。正式引流前逐一确认四个开放入口有真实、有效内容；没有内容时保留明确空态和提交需求入口，不伪造铺位数量。

分享仍使用 `pages/detail/detail?id=原ID`，无需重做历史收藏或分享路径。本轮未接入短信系统；后续短信只需承接到已核实的项目详情与咨询入口。

```markdown
# 项目/铺位资料（待运营核实）
- 资料提供人及核实日期：
- 发布内容：项目招商 / 具体铺位
- 商业场景：校园 / 社区 / 文旅 / 购物中心
- 项目/铺位标题：
- 商业项目/位置名称（校园填写学校名称、简称）：
- 所属项目 ID（仅关联铺位）：
- 城市、区、详细地址：
- 楼层/铺位位置：
- 项目/铺位介绍：
- 封面及详情图片（来源与授权）：
- 周边客群：
- 可招商面积下限、上限（㎡）：
- 基础月租下限、上限（元/月）：
- 押金、物业费、推广费、扣点、转让费等详细费用：
- 适合及不适合经营品类：
- 经营要求、证照/品牌准入：
- 排烟、燃气、上下水、电力等工程条件：
- 场景说明（营业时段/旺淡季/常驻要求等）：
- 看铺时间、预约方式：
- 当前状态与下次复核日期：
- 仅内部备注（不公开）：
```
