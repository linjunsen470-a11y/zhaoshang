# 前端视觉焕新

> 日期：2026-10-15
> 范围：微信小程序 `mp/`、公开网站 `backend/app/(frontend)/`、后台 `backend/app/admin/admin-theme.css`
> 目标：高级、简约、好看、专业。铺位图片是唯一的装饰，界面本身保持安静。

信息架构和业务入口保持不变。这次只调整材料、层级和排版。

## 视觉系统

三端共用同一套判断。小程序写在 `mp/app.wxss`，网站写在 `backend/app/(frontend)/globals.css`。后台保持现有深蓝工作色，只收字重、阴影和封面尺寸。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 纸色 | `#F6F4F1` | 页面底、导航栏、Tab 栏 |
| 墨色 | `#1C1A17` | 标题、租金、主按钮 |
| 次级文字 | `#6F6A62` | 地址、说明、未选中 Tab |
| 发丝线 | `#E7E1D8` | 分割、输入框、卡片边 |
| 松绿 | `#1F3D32` | 选中、链接、状态「招商中」 |
| 松绿浅底 | `#E7EEEA` | 选中底、适合业态 |
| 沙色 | `#F3EDE3` / `#7A6244` | 状态「即将开放」 |
| 危险红 | `#9F2D2D` | 删除和错误。不用于租金 |

表面只有一种：白底、1px 发丝线、圆角 12rpx，不加投影。按压只降低透明度。

字重两档：标题 600，正文 400。中文标题不加字距。金额不用 `word-break: break-all`。

导航栏改为纸色底、深色字。Tab 选中色改为墨色。选中与未选中图标使用同一套线框，只区分墨色和次级灰。

## 图标

用 1.5px 圆角线框，替换 emoji 和字符图标（🏫🔁🧊🛠、★☆☎➦📋、▣◎）。

- Tab 图标覆盖 `mp/images/tab_*.png`，画布 81×81。
- 页内图标放在 `mp/images/icons/`。
- 首页服务入口的 DOM 顺序保持：全部铺位、委托转让、餐饮设备、商铺装修。类名 `e2e-service-entry` 和 `data-action` 不变。

## 小程序

### 首页 `mp/pages/index`

收成四段，去掉深色渐变顶、蓝色渐变条和底部电话卡。

1. 页眉：名称「商业空间」，一行说明，发丝线搜索框，墨色「搜索」按钮。
2. 场景一行：校园、社区、文旅、购物中心。
3. 服务一行：全部铺位、委托转让、餐饮设备、商铺装修。线框图标，无独立大卡片。
4. 重点铺位横滑，然后是最新短名单。卡片只留图、标题、位置、月租。收藏不压在封面上。
5. 名单末尾一行文字链：「没有合适的，交给顾问」。

加载用与最终版式一致的骨架，不用居中转圈。缺图用纸色块加铺位名首字。

保留的测试钩子：`e2e-search-input`、`e2e-search-button`、`e2e-service-entry`、`e2e-recommended-card`、`e2e-latest-card`、`e2e-latest-favorite`。

### 找铺 `mp/pages/list`

筛选条吸顶，纸色底。选中项使用松绿字和 2rpx 下划线，去掉筛选项之间的竖线。

卡片：左图约 200rpx，状态写在图片左下角。右侧标题最多两行，下面一行「场景 · 面积」，月租在右下，墨色。适合业态最多两个。收藏在卡片右侧。

### 详情 `mp/pages/detail`

- 图片通栏，高度约 560rpx。
- 标题直接落在纸色上。小字是场景、类型和状态，铺位名在下，月租用 40rpx 墨色。
- 基础参数是两列定义列表，行间一条发丝线。地址右侧是「复制」。
- 适合业态用松绿浅底，不适合业态用纸色描边。
- 介绍、亮点、客群、合作、看铺放在同一内容区，用小标题分隔。
- 底栏左侧是收藏和电话两个图标，右侧一个主按钮。分享留在标题行，使用 `open-type="share"`。已满、已下架时主按钮变灰，文案不变。

保留 `e2e-project-status`、`e2e-project-title`、`e2e-consult-button`。

### 表单与「我的」

`apply`、`transfer`、`equipment`、`renovation` 共用 `apply.wxss`。页头改为纸色、标题和一句说明。必填星号用墨色。输入框为白底、发丝线、12rpx 圆角。

「我的」去掉深色背景和「意向商户」徽章。称呼与手机号直接排在纸色上。菜单用发丝线分隔。「收藏仅保存在本机」留在收藏行的次级说明。

设备列表的悬浮按钮改为墨色实心，不再使用蓝渐变。租金和价格不再用红色。咨询记录的状态色改为松绿、沙色和石色。

## 网站

`backend/app/(frontend)/page.tsx` 与小程序使用同一套纸色和墨色。

- 页眉纸色，主标题墨色。
- 左侧是服务说明列表，右侧放精选铺位图片。
- 去掉三块统计数字。当前数字只来自最多 6 条精选，其中「设备需求类型」固定为 3，不能当作总量。
- 费用用墨色。主按钮用墨色，聚焦环用松绿。

## 后台

`admin-theme.css` 只做三处：

- 眉题、表头、状态标签、导航分组标题的字重从 800 降到 600。
- `--cms-shadow` 改为无阴影，面板继续靠 1px 边线分开。
- 房源封面从 72×54 调整为 96×72。

不改后台的信息架构、主色和操作流程。

## 不改动

- 筛选维度、表单字段、提交和收藏逻辑。
- 测试用的 `e2e-*` 类名、`data-test` 和首页服务入口顺序。
- 顾问电话、隐私同意、已满和下架时禁用咨询。
