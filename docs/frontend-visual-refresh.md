以找铺为主，采用白色内容面、深绿主操作和浅灰绿分区。用清晰的信息顺序、真实图片、统一组件和完整状态建立成熟感。

| 轻分区 | `#F3F6F4` |

- 页面左右 32rpx；间距按 8rpx 阶梯组织；卡片与图片圆角 16rpx，输入与按钮 12rpx。
- 正文 28rpx、辅助信息 24rpx、标题 32–40rpx；正文 400、标题 600。标签可用 22rpx。
- 保留系统字体、原生导航和三个 Tab。按钮及图标操作至少 44px 点击区域。

## 小程序页面规则

### 首页与房源展示

首页顺序为定位与搜索、四类场景、四个服务入口、重点推荐、最新房源。服务入口保持「全部铺位、委托转让、餐饮设备、商铺装修」顺序。推荐采用上图下文，收藏放在信息区。列表共享 `mp/templates/property.wxml` 与 `mp/styles/project-card.wxss`，信息顺序为类型、标题、位置、场景与面积、业态、费用。

费用直接沿用商业展示层的 `priceLabel` 和 `priceText`，不把年费、综合费用强制标为月租。保留现有 `e2e-*`、`data-test` 与事件处理函数。

### 找铺与详情

找铺将场景和内容类型独立展示，主要筛选为区域、月租、面积、更多。业务、品类、状态和校园细类放在更多面板，先暂存、确认生效，取消不应用；非校园场景清理校园细类。已选条件可单独移除，收藏范围内重置不退出收藏，并提供返回全部房源的入口。

详情采用相册、标题与状态、费用与面积、空间信息、经营条件、介绍、所属铺位、合作与看铺的顺序。地址可复制，所属项目与铺位可互相访问。底栏保留收藏、电话与咨询，已满或下架不能咨询。

### 表单与辅助页面

四类表单共用 `apply.wxss`，按业务需求、联系方式、补充材料分组。共享表单 Behavior 负责字段报错与首错定位、加载重试和重复提交保护。找铺清空操作需确认，并保留当前咨询对象。

我的突出咨询记录和收藏；咨询记录使用摘要卡片、次级编辑和文字删除，保留删除确认。设备列表统一信息、图片、价格和发布入口。成功页以查看记录为主，隐私页改善阅读层级。

加载、空数据、无匹配结果、加载失败、图片失败、禁用和提交中状态都需检查。接口参数、商业字典来源、隐私同意、图片所有权和收藏存储规则保持兼容。

## 第一轮其他端记录

以下保留官网和后台的第一轮视觉记录，不代表本轮对这些界面进行了修改。

## 视觉系统

三端共用同一套判断。小程序写在 `mp/app.wxss`，网站写在 `backend/app/(frontend)/globals.css`。后台保持现有深蓝工作色，只收字重、阴影和封面尺寸。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 纸色 | `#F6F4F1` | 页面底、导航栏、Tab 栏 |
| 墨色 | `#1C1A17` | 标题、租金、主按钮 |
| 次级文字 | `#6F6A62` | 地址、说明、未选中 Tab |
| 发丝线 | `#E7E1D8` | 分割、输入框、卡片边 |
| 松绿 | `#1F3D32` | 选中、链接、状态「招商中」 |
| 松绿浅底 | `#E7EEEA` | 选中底、适合业态 |
| 沙色 | `#F3EDE3` / `#7A6244` | 状态「即将开放」 |
| 危险红 | `#9F2D2D` | 删除和错误。不用于租金 |

表面只有一种：白底、1px 发丝线、圆角 12rpx，不加投影。按压只降低透明度。

字重两档：标题 600，正文 400。中文标题不加字距。金额不用 `word-break: break-all`。

导航栏改为纸色底、深色字。Tab 选中色改为墨色。选中与未选中图标使用同一套线框，只区分墨色和次级灰。

## 图标

用 1.5px 圆角线框，替换 emoji 和字符图标（🏫🔁🧊🛠、★☆☎➦📋、▣◎）。

- Tab 图标覆盖 `mp/images/tab_*.png`，画布 81×81。
- 页内图标放在 `mp/images/icons/`。
- 首页服务入口的 DOM 顺序保持：全部铺位、委托转让、餐饮设备、商铺装修。类名 `e2e-service-entry` 和 `data-action` 不变。

## 网站

`backend/app/(frontend)/page.tsx` 与小程序使用同一套纸色和墨色。

- 页眉纸色，主标题墨色。
- 左侧是服务说明列表，右侧放精选铺位图片。
- 去掉三块统计数字。当前数字只来自最多 6 条精选，其中「设备需求类型」固定为 3，不能当作总量。
- 费用用墨色。主按钮用墨色，聚焦环用松绿。

## 后台

`admin-theme.css` 只做三处：

- 眉题、表头、状态标签、导航分组标题的字重从 800 降到 600。
- `--cms-shadow` 改为无阴影，面板继续靠 1px 边线分开。
- 房源封面从 72×54 调整为 96×72。

不改后台的信息架构、主色和操作流程。
