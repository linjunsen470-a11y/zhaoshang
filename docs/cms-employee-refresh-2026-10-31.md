# 员工后台调整（2026-10-31）

## 使用方式

- 工作台：录入房源、处理咨询、分享房源。
- 咨询收件箱：按开始和结束日期筛选，选择最新在前或最早在前；日期按北京时间，包含结束日期当天。筛选条件保留在网址中，翻页不会丢失。
- 用户管理：管理员可新增、修改和删除员工账号，填写姓名、邮箱、密码和角色。仅有管理员、普通用户两个层级；普通用户处理房源和咨询，不能管理其他账号或修改文档连接。
- 腾讯文档同步：查看状态、打开文档、立即同步；管理员展开“连接设置”维护参数。

用户管理面向后台员工，小程序客户仍通过微信登录。普通用户沿用数据库中的 editor 角色值，无数据库迁移。

## 腾讯文档连接

官方地址：`https://docs.qq.com/openapi/mcp`，HTTP 传输。官方服务的 Authorization 请求头直接使用个人 Token，不自动添加 Bearer 前缀。其他自定义 MCP 服务保留原 Bearer 方式。

- 文档：`NFVwfGTkzTfI`
- 房源表：`tbIrk4`
- 咨询表：`8fAWWA`

令牌只保存在被 Git 忽略的本地环境/同步配置及云端持久卷中，不回传浏览器。官方说明：https://developer.cloud.tencent.com.cn/mcp/server/11803

定时同步仍需单独启动 worker；保存连接不自动启用定时任务。
