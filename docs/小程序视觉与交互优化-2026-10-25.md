## 已实现

- 首页：场景建筑插画、连贯的渐变背景、找铺需求主入口、服务流程条；可咨询数量使用接口 `totalDocs`，没有增加学校覆盖量或响应时限等未经核实的数据。
- 房源卡片：推荐图统一 4:3；场景标签降为次级灰，压缩区块和首行间距，普通招租不再重复标注；数字租金带千分位，单位单独显示，面议卡片使用简短摘要。
- 找铺筛选：不再重复显示顶栏场所分组 chip；更多面板支持防抖统计结果数、过期请求保护和失败时退回确认按钮；取消不改变已应用条件。
- 详情：页面标题跟随场所、吸顶内容导航、醒目的分享按钮、费用拆分与未识别内容保留、顾问联系卡片及最多三条同场景房源。
- 收藏：共用反馈函数；按后续要求取消震动和星标缩放，仅保留收藏状态和文字反馈。
- 分享：首页、找铺页和详情页支持朋友分享及朋友圈数据，详情使用房源封面。找铺分享不携带收藏或浏览记录 ID。
- 我的：真实咨询和收藏数量、最近浏览入口、微信昵称输入。最近浏览仅存房源 ID，最多 20 条，重复浏览置顶；展示仍经公开房源接口过滤。
- 咨询记录：三段处理进度、摘要及展开详情，编辑和删除收进详情；「已结束」仍表示处理结束。
- 表单与成功页：咨询、编辑和提交成功使用各自页面标题；选择器和关闭按钮改为 CSS 图形；提交后说明需求确认、房源匹配和预约看铺的后续步骤。
- 展示文案：去掉页面图片角标和表单上下文中的「演示」「示意」等字样；房源展示层继续清理存量标题和说明中的内部标识，原始存储及客户填写的备注不改写。
- 包体：移除三张不再使用的场景照片和四张旧场景图标；本地存量图片路径自动迁移到保留素材。

## 验证方式

- `node scripts/mp-check-templates.mjs`：微信 WXML/WXSS 编译。
- `node --test --test-isolation=none tests/unit/*.test.mjs`：包含费用保真、收藏 ID、浏览记录上限和筛选计数竞态检查。
- `node --test --test-force-exit --test-isolation=none tests/mp-interface.test.mjs`：开发者工具筛选及表单交互。
- `node --test --test-force-exit tests/mp-ux-refresh.test.mjs`：开发者工具中的发现、收藏、浏览、提交、修改和删除流程。每组重开开发者工具项目、仅使用本地数据，检查结束恢复原有 Storage 与应用状态。
- 可设置 `MP_UX_SCREENSHOTS=1` 保存界面截图到 `test-results/ux-review-20261025/`。截图 RPC 使用单独超时，避免将工具无响应误判为业务失败。

真实微信分享发送、真机触感和订阅消息不由本地自动化断言。订阅通知、企微二维码和地图导航需要相应的模板、顾问资料或坐标，本次没有添加缺少数据的入口。
