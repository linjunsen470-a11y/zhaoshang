# 腾讯文档同步 Demo 操作说明

本轮实现的是简单的房源导入、咨询回写和跟进回读，没有增加多轮审批或完整 CRM。

## 运行与查看

```powershell
pnpm demo:connected
```

此命令同时启动 Next/Payload 和一个轻量同步进程。默认地址是 `http://127.0.0.1:3000`；管理员入口为 `/admin/workspace/sync`。也可以分别启动 `pnpm dev` 与 `pnpm --dir backend sync:tencent:watch`。

本机联调使用独立数据库 `zhaoshang_tencent_demo_20261024`。旧 `zhaoshang` 数据库保留，原库备份和旧配置保存在忽略提交的 `scratch/backups/`。独立库的专用 demo 管理员登录信息在本机 `backend/.tencent-sync/demo-login.json`；没有复制旧库认证数据。

当前腾讯文档：[学校商铺招商管理表](https://docs.qq.com/smartsheet/DTkZWd2ZHVGt6VGZJ)。房源表 ID 为 `tbIrk4`，新增客户咨询表 ID 为 `8fAWWA`。连接页已填入这些 ID，可更换为其他适配表。

## 配置无人值守连接

1. 在后台“腾讯文档同步”填写自己的 MCP 服务地址，按服务接入说明选择 Streamable HTTP 或 SSE。
2. 如果接入地址本身已含凭证，可将独立 Bearer Token 留空；否则填写服务要求的 Token。
3. 保存后点击“检测已保存的连接”，确认当前文档、工作表和所需字段可访问。
4. 点击“立即同步”，查看实际新增、更新、跟进回读和失败记录。
5. 勾选“启用定时同步”并保存，默认每 15 分钟运行一次；同步进程必须保持运行。

地址及 Token 保存后不回显，空白表示保留原值；单独 Token 可勾选清除。`backend/.tencent-sync/` 已加入忽略规则，不应提交或共享。环境变量 `TENCENT_DOCS_MCP_URL` / `TENCENT_DOCS_MCP_TOKEN` 可覆盖本地配置。

聊天插件登录与后台连接是两份授权。本次先通过聊天插件读取真实文档数据，再执行一次明确标识的 snapshot 导入，以便在后台看到效果；这不表示后台已持有插件的登录凭证。只有填写并测试自己的服务地址后，无人值守的手动/定时链路才会连接腾讯文档。

## 在小程序看到后台数据

1. 使用微信开发者工具打开 `mp/`，保持本地后台运行。
2. 开发者工具中按本地联调要求关闭请求合法域名校验。
3. 打开“我的”，点击“Demo：连接本地后台”。此入口仅开发版显示。
4. 回到首页或找铺页，页面会重新读取 `http://127.0.0.1:3000/api` 的房源。
5. 提交一条咨询，在后台咨询收件箱查看；立即同步或等定时任务后到腾讯文档“客户咨询”工作表查看。

默认本机 Storage 演示模式仍保留，可再次点击切回。仅在本机 Storage 中保存的房源、咨询和个人资料不会自动上传；连接后台后新提交的咨询才进入本轮同步。真机不能直接访问开发电脑的 `127.0.0.1`，需另配可访问地址；体验版/正式版仍沿用其发布配置要求。

## 本轮同步规则

| 内容 | 同步规则 |
| --- | --- |
| 房源 | 腾讯文档 → 后台，以文档、工作表和记录 ID 稳定匹配；重复运行不重复新增 |
| 图片 | 保存到后台媒体库；请求携带文档来源头，按图片域名和大小限制读取；样例图保留演示标识 |
| 招租状态 | 招租中/洽谈中 → 开放中，已出租 → 已满，暂停招租 → 已下架；资料不合格则列出失败原因 |
| 金额 | 保留原单位与费用明细；年租和每平方米月租可计算基础月租，抽成不混算为租金 |
| 客户资料 | 后端 → 文档，仅导出称呼、电话、咨询类型、需求、关联房源和提交时间 |
| 跟进 | 文档的处理状态和内部备注可回读；客户自己提交的内容、OpenID 和原始快照不被回读覆盖 |
| 并发跟进 | 两侧同时修改同一跟进内容时报告冲突，不静默覆盖 |
| 客户撤回 | 源咨询已删除时，将文档记录标记“已撤回”；不自动物理删行，副本个人资料由管理员按需清理 |
| 房源删行 | 不根据缺失行自动删除后台房源，使用明确的“暂停招租”状态控制下架 |

客户导出前检查文档文件级共享策略，拒绝向“所有人可读/可编辑”文档写入个人资料。隐藏列与筛选视图不作为权限隔离。OpenID、令牌、原始快照和用户附件不导出。

本次城市字典加入广东城市选项，区域仍以原广州区域及本次示例的南山、松山湖为主；新区域须补字典，不会把未知位置猜成广州。

## 校验与部署边界

同步测试覆盖字段白名单、金额单位、幂等、跟进回读、撤回标记、公开共享阻止、分页异常、凭证不回显，以及真实 HTTP MCP 协议握手。真实微信流程需要在开发者工具和真机继续验收。

本次实测记录：三条腾讯文档样例房源及图片已导入；两条虚构咨询经真实 HTTP 提交并通过聊天连接写入客户表；其中一条“已联系”及备注已回读到后台。浏览器实测配置保存、权限与响应式界面通过；微信开发者工具实测“我的”后台切换、三条真实后台房源列表及隐私页通过。尚未填写后台独立 MCP 凭证，因此本次真实腾讯文档读写由聊天连接执行，未将其当作无人值守同步验收。真机验收尚未执行。

同步进程使用本机 JSON 配置和状态，适合当前单机 demo。后台与同步进程须在同一 backend 工作目录运行。当前 Compose 生产镜像没有配置独立同步进程及状态卷，不应据此声称生产容器已启用定时同步。

数据库变更仍须先备份，再显式运行 `backend/scripts/push-schema.ts`；日常运行保持 `PAYLOAD_DB_PUSH=false`。
