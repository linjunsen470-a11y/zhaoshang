## 本轮未采用的扩展

- 自动草稿：需要明确联系人、附件的本地保存期限、编辑模式隔离和提交后清理，不能只把整个表单写入 storage。
- 地图：没有经过核实的坐标，不以行政区中心冒充房源位置；继续遵守学校信息脱敏规则。
- 排序：全局排序需在 API 与分页前统一处理，不能只给当前页排序；面议、抽点和月租也不能混作一个可比较数值。
- 设备分页：当前 API 返回列表，需与服务端分页契约一起改；本轮不做看起来能翻页但实际仍一次拉全量的界面。
- 装修风格/预算标签：缺乏业务确认的选项，不硬编码假定偏好。
