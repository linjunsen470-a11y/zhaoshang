# 咨询联系方式与微信授权

找铺、转让、设备和装修表单均要求提供手机号；用户可以手动填写，也可以点击“微信授权获取”。称呼为选填，补充说明直接显示。隐私提示和提交按钮固定在表单底部。

手填号码按 `mp/config.js` 中的大陆手机号规则校验。微信授权被拒绝或失败时保留已手填号码；授权请求进行中防止重复操作，成功后回填号码。授权不代替表单中的隐私同意。

`POST /api/auth/wechat-phone` 接收微信一次性授权码并要求小程序登录凭证；后端通过微信服务换取号码，校验水印及号码格式。仅服务端持有微信密钥，响应不缓存，也不返回密钥或上游原始错误。本地演示数据模式下，微信授权仍需可用的真实授权后端。

上线前需配置真实 HTTPS API、对应合法域名及微信手机号获取能力，并在微信小程序隐私保护指引中如实声明手动填写和授权获取的用途。真实授权与真机体验需要在具备权限和配置的环境单独验证；模拟返回不能算真实微信授权通过。
