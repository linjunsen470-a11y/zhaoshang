## 网站与小程序备案是两项服务

1. 核实域名注册商、域名实名认证及主体名称是否与营业执照一致。准备好主体及网站负责人真实资料，以实际接入商及广东管局的要求为准。
2. 核实现有大陆云服务器的接入服务商及备案资格，向实际接入商申请网站备案并完成实名认证、短信核验及审核。若变更或新增接入商，按接入商要求办理相应接入手续。Railway 的境外部署地址不能代替网站的大陆接入资源。
3. 网站备案通过后，将**网站服务备案号**填入 `website/js/main.js` 的 `SITE_ICP_NUMBER` 并重新部署；勿使用示例号。页面会显示并链接至 [工信部备案系统](https://beian.miit.gov.cn/)。
4. 在微信公众平台核实小程序主体与企业一致，按平台要求提交**小程序服务备案**及实名认证。已拥有网站主体备案不代表小程序已经备案，可能可复用主体信息，具体以平台流程为准。取得以 `X` 结尾的小程序备案号后，填写 `mp/config/index.js` 的 `MINIPROGRAM_ICP_NUMBER`，将显示在「我的」页面。
5. 如果实际业务涉及需要许可、专项审批、特定类目资质等，以主管部门、微信审核和经营范围为准；不要仅凭静态网页推断是否免除许可。按实际提供的功能填写微信隐私保护指引，并确认手机号授权等能力已开通。

参考：[工信部 APP 备案解读](https://www.miit.gov.cn/jgsj/xgj/hlwgl/art/2023/art_564bf0759d7e41d5b4aa8ce4996b9e84.html)、[广东省通信管理局公告](https://gdca.miit.gov.cn/bsfw/bszn/jyxk/tzgg/art/2022/art_da255ff756604fd5afe158c2fa96a17f.html)、[小程序备案号格式](https://support.huaweicloud.com/icp_faq/icp_05_0251.html)、[Railway 静态网站部署](https://railway.com/guides/static-hosting)。

Railway 控制台目前提示将根域名 CNAME 指向 `nud58xnl.up.railway.app`，并添加 `_railway-verify` TXT 所有权记录；**本次没有修改 DNS**。根域名 CNAME 与现有记录可能冲突，请在 DNS 服务商处核对记录类型、邮件服务及备案接入安排，必要时向服务商确认是否支持根域名 CNAME/ALIAS。TXT 记录的当前值以 [Railway 服务设置](https://railway.com/project/cea5cce1-8322-4a34-9b3c-f11bd72bd601/service/3f00ed91-8c40-48e1-b17f-63d75c739232)为准；域名未验证期间证书尚未签发。网站通过 CLI 上传，不会随 Git 提交自动部署，重新发布步骤见 [网站说明](../website/README.md)。

向公众平台添加实际使用的 request、uploadFile 和 downloadFile 合法域名；如图片来源还有其他域名，逐一按微信当前规则配置。白名单填写域名，不带 `/api` 路径；保留默认域名校验，使用真实网络和证书复测。只有联调本机 HTTP Mock API 时才临时关闭开发工具的域名校验，结束后重新开启。具体界面字段以微信当前页面为准。

## 现有 API 路径

后端已有 `/api/auth/wechat-login`、`/api/auth/wechat-phone`、`/api/projects`、`/api/equipments`、`/api/leads` 及 `/api/uploads/lead-image` 等接口。小程序只在 `mp/services/` 发请求；API 地址只是公共前缀，不需要为每个页面再单独配置。线索访问、上传附件与后台管理各有鉴权边界，不能用开发 OpenID 替代正式微信登录。

2026-10-31 已定位并修复本机演示库结构落后造成的房源查询故障：先在隔离副本验证，再显式更新本机演示库；房源列表及图片已恢复。按用户要求，历史演示备份及临时副本已清理。接口在数据库异常时仍只返回通用 500 提示，不向小程序暴露内部 SQL。其他部署环境需分别核实数据库连接及 schema，先备份再执行显式更新；详见 [同步修复记录](tencent-sync-fixes-2026-10-29.md)。

小程序连接统一在 `mp/config/environments.js` 配置。当前开发版直接连接腾讯云 HTTPS API；本地模拟需显式设置 `useLocalMock: true`。体验版和正式版仍需单独填写地址。

## 发布前必须完成的验证

- 在真实目标环境执行 `pnpm launch:check`，并分别检查线上环境配置；此命令只做静态配置检查，不验证 DNS、证书、备案真伪、微信白名单或部署健康状态。
- 使用隔离测试环境验证微信登录和手机号授权、两个用户的咨询和附件隔离、401 刷新、编辑/删除，以及项目草稿不可公开；勿向生产客户数据库写入测试数据。
- 微信开发者工具及 iOS/Android 真机检查合法域名、图片上传/预览、隐私同意与政策、顾问电话、数据删除、分享和全部受影响页面。
- 制定并落实实际数据保存、删除与备份管理流程；政策中的处理方式必须与实际运营一致。腾讯文档协作同步启用时，确认访问权限及删除后的副本清理。
- 检查备案号、网站链接、真实房源和服务类目。以上未完成前，不将演示模式或 Railway 临时站点视为小程序正式上线。
